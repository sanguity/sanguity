Connected sources

Instead of downloading exports, connect a patient portal by signing in to it. Sanguity then pulls what's new on a schedule, straight from the vendor to this server. Every pull is an import you can undo from the import history, and nothing is contacted until you connect a source.

Connect a source

No source is set up on this server yet. Each server registers its own app with each vendor, so your admin sets each one up first: ask them for the portal or health plan you use.

As an admin, you set sources up (each vendor's app for this server) under Admin → Connected-source apps.

You can view this profile's connections; its owners and editors can connect sources.
