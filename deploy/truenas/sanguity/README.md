# Sanguity

[Sanguity](https://github.com/sanguity/sanguity) puts your medical records, insurance claims and wearable data on
one private timeline, on your own server.

After installing, open the Web UI and enter the one-time setup code from the logs of the **app** container to
create the first account. Keep a copy of the **Encryption Key** dataset somewhere other than the data and its
backups: without the key, the records can't be read.
